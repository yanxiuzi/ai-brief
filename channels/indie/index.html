工具与栈

CATT 0.2.1 开源：在 CI 里测你的 agent 服务，专治「跑一次一个样」

Consumer Agent Testing Tool 开源，用来对着 Muse、Instinct 这类专有助手反复迭代。作者点明了痛点：agent 的记忆和账号状态让测试无法复现，而可重复、可靠的测试正是迭代的前提；他们做这个工具，最初是为了减少自己给这些 agent 写 MCP/API 时的挫败感。

对你的价值：只要你做 agent 产品，就必须把「同一输入两次运行结果不同」当成 bug 而不是特性。今天就能做的最小动作：把 agent 的会话状态显式落库、测试前重置账号快照、把关键路径放进 CI。没有可复现性，后面所有定价和 SLA 都无从谈起。
来源：Hacker News / https://github.com/Coverage-Cat/consumer-agent-testing-tool
