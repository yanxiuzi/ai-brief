产品与收入

一个独立创始人支撑 $600K ARR 的 B2B SaaS，用 10% 股权换一个远程 CTO

HN 上一条招聘帖：一家 bootstrap 的 B2B SaaS，年收入 $600K、利润 $250K、1,600 个客户，做的是帮在欧洲大型电商平台上卖货的商家做生意的工具。创始人要找一名远程、独立负责的 CTO；这名 CTO 将是公司唯一的工程师，获得 10% 股权。

对你的价值：两个可以直接参考的基准：1,600 个客户撑起 $600K ARR，年均客单约 $375（月均约 $31）；利润率约 42%，靠的是没有销售团队和极低的人力成本。你在给小 B 工具定价时，这个区间比任何「SaaS 定价指南」都真实。另外要留意它接入新负责人的方式：不招团队，只招一个对全部工程负责的工程师，并用股权支付；现金紧张但增长稳定的一人公司常这么做，这也意味着交出 10% 换来的必须是能长期坚持的人，而不只是能写代码的人。

工具与栈

OpenCode 上线 Browse：让 coding agent 自己去看网页

OpenCode 发布 Browse 产品（opencode.ai/product/browse），在 HN 上拿到 62 points、31 条评论。

对你的价值：agent 缺的通常不是写代码能力，而是正确的上下文：第三方文档、控制台里的配置页、某个 API 的示例。给它一个浏览器，补的就是这块。试的时候盯两件事：抓到的内容是否可复现（同一个 URL 两次结果不同就没法 debug），以及抓取失败的边界会不会被 agent 当成「页面上没有这条信息」而继续往下写。二选一都要在 prompt 里明确禁止。
来源：https://opencode.ai/product/browse

增长与渠道

HN 上的吐槽：十个新 AI SaaS 站，九个像一条编辑器命令

一条 HN 讨论问：是不是九成新的 AI SaaS 网站，看起来都只该是编辑器里的一条命令？这条帖只有 5 points、2 条评论，但同期 HN 上还出现了「写了 100 个 SaaS 点子，每个都带买家、定价和 MVP 计划」这类内容型帖子，两个信号说明的是同一件事。

对你的价值：这条吐槽真正的用处是反向定位。如果你的产品能被一句 prompt 替代，那发布到 Product Hunt 也只是排着队被淹没，因为你和另外九个人在争同一个位置。要么绑进用户已经在用的工作流（编辑器、会议、邮件），要么去解决需要持续状态和权限的问题：数据积累、多人协作、合规留痕。这类东西一句 prompt 做不出来。
来源：https://news.ycombinator.com/item?id=50455964

踩坑与风险

Optimizely 遭入侵，被用来向 Zoom、GitLab 等站点投递恶意代码

报道称 Optimizely 被入侵，并被用来在 Zoom、GitLab 等大型品牌的网站上投放恶意软件。同一话题在 HN 上出现两条，分别 18 points 和 72 points。

对你的价值：你网站里那几行第三方脚本——A/B 测试、分析、客服挂件、热图——跑在别人家的服务器上。供应商一旦被攻破，你的域名、你的用户、你的支付页就一起中招，而受害者名单上写的是你的品牌。这周花十分钟做一件事：列出页面上所有外链 JS，能 self-host 或能删的先删，必须保留的加 integrity 与 CSP；支付和登录页面原则上不该出现任何第三方脚本。
