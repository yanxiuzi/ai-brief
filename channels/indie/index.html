产品与收入

Kagi 公测 Kagi Mail：付费、无广告、开放标准的邮箱

Kagi 此前已经推出付费搜索和对标 Chrome 的 Orion 浏览器，11 月 23 日又宣布 Kagi Mail 进入公测，卖点是「无监控、无广告、开放标准、无锁定」。这是它第三个直接与 Google 竞争的产品。

对你的价值：如果你想做「用户付费，换取不被变现」的产品，Kagi 是目前最完整的样本：搜索、浏览器、邮箱卖给同一批付费用户，彼此互相带量。反过来也要想清楚：用户付的这笔钱，买的就是「不把我当广告库存」。
来源：The Verge，2026-11-23，https://www.theverge.com/tech/1041000/kagi-mail-email-google-gmail-alternative

工具与栈

localcode：一条命令在 Mac 上跑本地模型的编程 Agent

安装只需三步：uv pip install localcode、cd 进项目、运行 localcode。它的定位是「Agentic coding. Local models. On your Mac.」，模型全部跑在本地，能在项目里读文件、改文件、跑测试、执行命令；权限有范围限制。

对你的价值：想验证「本地模型够不够用」不必先搭环境，三行命令就能开测。适合跑涉密代码，或不想把仓库传到云端的活；先在小仓库上试，确认它怎么处理测试失败和回滚，再放到主项目上。
来源：OSCHINA，2026-11-23，https://www.oschina.net/news/503746

增长与渠道

MCP server 正在成为新的分发入口

Hissing Kitty 上线了免费 MCP server，让你在续订任何 SaaS 之前先问自己的 AI；FigmaMCP 则让 Claude Code 或 Codex 直接编辑你打开的 Figma 文件。两者做的都是同一件事：把功能放进 AI 客户端的调用路径里。

对你的价值：过去争的是搜索排名，现在争的是「AI 会不会调用你」。把核心能力包成一个 MCP server 的成本很低，可以先免费放出去试水；但你必须假设用户不会为此专门打开你的网站，所以每次调用都要在结果里留下能被记住的痕迹，例如署名、来源或下一步动作。
来源：Hacker News / Product Hunt，2026-11-23，https://hissingkitty.com/developers

踩坑与风险

维护者不需要更多 AI bug 报告，他们需要修复

GitHub 与 Microsoft 的 Codename MDASH 试点把数千条原始 AI 发现整理成 99 条经核查的私有报告，并附上修复建议，覆盖六个被广泛使用的开源项目，维护者已经修复过半。GitHub 给出的结论很直接：维护者不需要更多 AI bug 报告，他们需要修复。

对你的价值：用 AI 批量扫依赖、批量提 issue 或 PR，短期看起来像是在贡献，长期是在消耗自己的信誉，因为维护者一眼就能认出没有复现步骤的报告。要用 AI 提问题，你就自己先复现、带上补丁，学那 99 条的做法，而不是那数千条的。
来源：The GitHub Blog，2026-11-17，https://github.blog/open-source/maintainers/maintainers-dont-need-more-ai-bug-reports-they-need-fixes/
