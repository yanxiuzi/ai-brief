产品与收入

前 SDET 单人做的 VoiceGremlin：给 AI 电话代理写自动化测试

VoiceGremlin 是面向 AI 电话代理的自动化测试 SaaS，作者自称前 SDET、现在是这个产品的单人开发者。用法是给 API 一个电话号码加一条测试用例（例如「验证 agent 会做 X」），它让机器人之间互相对话完成测试，再用 LLM-as-judge 给出 pass/fail 结果接进你的流水线。目前状态是可完整运行、有免费试用、不需要信用卡。

对你的价值：语音/客服 agent 正在批量上线，但「怎么验收」几乎没人做，这是一人公司能切进去的窄缝。免费试用不绑卡降低了使用门槛，代价是你必须在试用期内把价值演示清楚，否则全是白嫖流量。这套「输入号码 + 用例 → 机器人互打 → LLM 判定」的形态，可以直接搬去测你自己的 agent 功能。
来源：Hacker News（Show HN）— https://voicegremlin.com/

工具与栈

Whistle：16.9 MB 的语音转文字

cactuscompute 发布的 Whistle 把语音转文字做到 16.9 MB，在 HN 首页拿到 573 分，是当天热度最高的条目之一。

对你的价值：体积小意味着能塞进端侧（浏览器/手机/桌面），既不必为转写单独付云端 API 费用，也不必把用户音频传出去——这在隐私敏感或按次计费的产品里是很硬的卖点。可以据此重新评估：产品里哪些 AI 能力其实能本地做，把成本结构从「每次调用付费」改成「一次性打包」。上线前一定要跑真实的中文、口音、噪声场景，端侧小模型在长音频上更容易翻车。
来源：Hacker News — https://cactuscompute.com/blog/whistle

增长与渠道

OnlyFoundrs：把 SaaS 目录站这件事自动化

OnlyFoundrs 自称是「第一个自动化目录」，做的是自动化的 SaaS 目录站。

对你的价值：产品目录/榜单一直是免费曝光的常规操作，现在连目录本身都在被批量化生产。这有两面：提交成本会更低、能批量覆盖更多目录；但目录站会迅速同质化、权重被稀释，甚至被搜索引擎判为低质站。别把「提交目录」当成增长主线，当顺手做掉的一步，重点还是落地页本身的转化。
来源：Hacker News — https://onlyfoundrs.com/
