GitHub 上 home-assistant/home-assistant.io 的 issue #49314 标题为「我从未授权过一个会扫描我 secrets 的集成」，在 Hacker News 上获得 154 分、102 条评论。

对你的价值：第三方集成、插件、npm 包、Docker 镜像都可能读到你进程里的全部环境变量——而你通常为了省事，把数据库密码、Stripe 密钥、模型 API key 全塞在同一个 .env 里。动作：把凭证按用途拆开（只读 key、按服务限额），不要把生产密钥和本地开发放在同一份配置里；装任何新集成前先看它申请了什么权限。
