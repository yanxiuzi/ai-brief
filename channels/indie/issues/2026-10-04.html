踩坑与风险

有人被精准钓鱼：借 git post-checkout hook 偷开发者凭证

Lobsters 上《I got targeted: Trying to get your credentials via a git post-checkout hook》记录了一次针对开发者的定向攻击，手法是通过仓库里的 git post-checkout 钩子在 checkout 时执行脚本、窃取凭证。

对你的价值：你在 clone 或 checkout 一个陌生仓库、审一个 PR 的代码时，就可能被动执行对方写的脚本，本机的长期凭证、SSH key、云 token 会被打包带走。今天就能做的：检查最近 clone 的仓库里 .git/hooks 和仓库配置有没有可疑内容；把本机长期有效的云凭证换成短时效凭证；让 CI 密钥和本机开发环境彻底隔离。
来源：Lobsters（2026-10-02）https://frankwiles.com/posts/i-got-targeted/
