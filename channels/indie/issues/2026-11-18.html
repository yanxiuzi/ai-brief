增长与渠道

EXA 联合创始人：agentic search 不是找页面，而是拼答案

Stack Overflow 播客中，EXA 联合创始人 Jeff Wang 说 agentic search 不是「找到页面」，而是「组装答案」，为此需要支撑万亿级 agentic 搜索的规模、自建 embedding 与向量数据库，并对网上海量冗余内容做去重，才能给出高可信答案。

对你的价值：这直接影响你的内容策略：别再只为关键词排名写页面，要写「能被拼进答案」的可引用段落——明确结论、明确数据、明确适用范围，并全站去重。同时这也是产品机会：帮中小企业做「答案友好化」改写和事实校验，是现在就能接活的咨询型产品。

踩坑与风险

Java4Shell：OpenJDK 处理 Base64 时的 RCE，Java 17 属预认证风险

Hacker News 首页热帖 Java4Shell（341 分、84 条评论），描述 OpenJDK 在处理 Base64 时存在 RCE；另一篇分析文章将其标注为 Java 17 的预认证 RCE，编号 CVE-2026-114938。

对你的价值：预认证意味着攻击者不需要账号就能打。如果你的后端、自托管产品、内部工具链里有任何 Java 服务对外可达，今天就应该确认版本并安排升级窗口。一人公司没有安全团队，这类补丁只能靠自己盯上游公告，建议把「关键运行时 CVE」列进每周固定检查清单。
来源：Hacker News / calif.io（https://calif.io/java4shell/、https://www.aikido.dev/blog/java-17-rce-vulnerability-cve-2026-114938）

今天就能做

  • 今天核对所有对外可达的 Java 服务版本，按 CVE-2026-114938 安排升级；同时把 Git 升到修复递归克隆、引用处理、合并、二进制补丁与 import 六类漏洞的版本。
  • 给关键依赖做一份「不可消失」清单：锁定版本号、自建镜像或 vendor 到自己的仓库，确保上游仓库下架时你仍能离线构建（ONNX Runtime 从 GitHub 消失就是现成案例）。
  • 把官网和文档里的核心页面改写成「可被拼进答案」的结构：先给结论和数字，再给适用范围；然后用 TruLata / RankSpot 这类工具实测一次 ChatGPT 提到你品牌的概率，作为基线。
