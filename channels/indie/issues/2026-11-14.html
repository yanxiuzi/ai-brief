AI agent 公司 LangChain 估值达到 30 亿美元，其模型与平台无关的 agent 管理工具 LangSmith 声称已有 7,000 个客户。资本愿意为“管 agent、看 agent、调 agent”这层付费，而不是为又一个 agent 应用付费。

工具与栈

GitHub 官方指南：把 agent 技能写成可 review 的文件

GitHub 在博客里给出 agent skills 的实践指南：把可复用的工程工作写成文件，团队可以 review、可以复用；但工具、项目上下文和权限仍然绑定在运行它的宿主上，不能跨宿主直接搬。

对你的价值：这给一人公司一个具体的知识沉淀方式——把你反复让 AI 做的事（建站检查、发版清单、客户邮件模板）写成仓库里的技能文件，下次换模型或换工具时迁移成本最低。别把关键工作流只存在某家产品的私有配置里。

增长与渠道

Agentic search 不返回页面，而是直接拼答案

Stack Overflow 访谈了 EXA 联合创始人 Jeff Wang，谈到支撑海量 agentic 搜索所需要的规模、从零构建自定义 embedding 和高性能向量数据库的技术复杂度，以及必须对网络上大量冗余内容去重，才能给出高可信度的答案。

对你的价值：当用户的搜索被“组装成一个答案”而不是“点开十个链接”，靠 SEO 拿点击的老路会持续衰减。独立开发者的对策是缩短路径：让产品本身成为被 agent 读取的数据源（结构化页面、公开 API、清晰的文档），而不是只优化标题党。

踩坑与风险

Git 修复 6 个安全漏洞，涉及递归克隆与合并

Git 官方发布更新，修复 6 个安全漏洞，影响范围包括递归克隆（recursive clones）、引用处理、合并、二进制补丁和导入。

对你的价值：这不是“以后再说”的升级。如果你或你的 CI 会执行 git clone --recursive，或者会处理外部提交的补丁和仓库，今天就该升级 Git 版本并检查流水线里这些命令的来源。一人公司没有安全团队，唯一能做的就是及时打补丁。
来源：The GitHub Blog，2026-11-10 https://github.blog/open-source/git/git-security-vulnerabilities-announced-7/

今天就能做

  • 升级本地和 CI 环境里的 Git 版本，并排查所有 git clone --recursive 以及处理外部补丁、外部仓库的流水线步骤。
