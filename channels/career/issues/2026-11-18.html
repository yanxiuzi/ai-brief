哈佛研究：AI 编码代理把瓶颈推到了 code review

Hacker News 首页热帖引用哈佛研究结论：AI coding agent 普及后，工程瓶颈从写代码转移到代码评审。GitHub 官方博客同期的说法是「写代码变快了，代码周边的工作没变快」，并把这套流程称为 agentic engineering：计划、写码、评审改动、排查线上问题，其中仍有大量工作依赖人的判断。

对你的价值：如果你的核心卖点还是「写得快」，价值正在被压缩；能审、能判断改动风险、能在线上定位问题，才是当下稀缺的。具体做法：简历里把「评审过多少量级的变更、拦下过什么问题」写成事实，面试时主动要求做一次 code review 演练。

「现在每个人的简历都完美了」，招聘官靠什么区分你

Stack Overflow 技术招聘官 Tom Harvey 在 Q&A 中给出的前提很直白：所有人的简历看起来都完美，那怎么找到合适的人？这篇题为《How do you hire a human?》的访谈讨论的正是同质化简历下的筛选逻辑。

对你的价值：简历被 AI 抹平之后，比拼的是可验证的东西：真实项目、能跑起来的代码、能讲清取舍的复盘。与其继续堆关键词，不如准备两三个「我做了什么决定、代价是什么、结果如何」的具体案例，把不确定性讲出来——这恰恰是包装不出来的部分。
