GitHub 推出 ReviewBench，一个面向代码评审 agent 的开放基准：基于真实 GitHub pull request，采用多来源 ground truth、统一评估标准，并按严重程度、类别和 precision-recall 偏好做拆分；其语言、仓库规模和规模分布参考了 GitHub 上超过 1 亿个真实 PR，并由资深工程师独立验证。GitHub 称，借助它，Copilot code review 的离线评估更能预判线上实验的方向。

对你的价值：AI 评审工具被量化，意味着「会用 AI 提 PR」不值钱了，「能定义评审标准、区分问题严重程度、控制误报率」才值钱。面试时主动问团队：你们怎么衡量 AI 评审的质量？如果你能讲清 precision 与 recall 的取舍，会立刻区别于只会用工具的人。
