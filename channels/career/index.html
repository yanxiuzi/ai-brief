GitHub 发文《Build once, run on any agent: A practical guide to agent skills》，指出 agent skills 能把可重复的工程工作沉淀成文件，供团队审查和复用；而工具、项目上下文和权限仍然取决于承载它的宿主环境。

对你的价值：这是可以拿给面试官看的产出：把你怎么用 AI 的流程固化成一份仓库里的技能文件、脚本或 SOP，比在简历上写会用某款 AI 工具更有说服力。它证明你的经验能复制给团队，而不只是你一个人的手感。

GitHub 与微软的 Codename MDASH 试点，把数千条 AI 原始发现转成 99 条经过核查的私有报告，并附上建议修复，覆盖 6 个被广泛使用的开源项目，维护者已经修复了其中一半以上。

对你的价值：这说明贡献开源项目时，带修复的 PR 比堆问题单更能积累信誉。对想进好团队的应届生和转行者，挑一个你日常在用的开源项目，提一个小而完整的修复，比简历上写熟悉某某技术更能被验证。
