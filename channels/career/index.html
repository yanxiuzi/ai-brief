技能与岗位

Stack Overflow：别让你的编码 agent 给自己打分

Stack Overflow 博客指出，AI 编码 agent 现在可以写设计文档、做前端原型、端到端实现整个项目——但不应该被信任去验证自己的代码是否真的能跑。同一博客的另一篇访谈里，Airbnb CTO Ahmad Al-Dahle 提到，AI 编码工具反而对软件工程团队提出了更高的判断力要求。

对你的价值：你的稀缺性正从「写得出来」转到「验得出来」。具体做法：面试时准备一个你如何定义验收标准、如何构造反例和回归用例的完整案例；日常工作中，凡是 agent 交付的模块都留一道独立验证步骤（独立环境跑、独立测试集、独立人 review），并把这个习惯写成你汇报里的固定项。
来源：Stack Overflow Blog；https://stackoverflow.blog/2026/11/13/your-coding-agent-shouldn-t-grade-its-own-homework/

求职方法

Stack Overflow 招聘官：现在每份简历都「完美」了

Stack Overflow 博客发布与技术招聘官 Tom Harvey 的 Q&A，标题直接点出问题：每个人的简历现在都很完美，那你怎么找到合适的队友？文章讨论的是在 AI 让简历和自述高度同质化之后，招聘方靠什么做区分。

对你的价值：简历打磨的边际收益在快速下降。把精力挪到「可验证的东西」上：能跑的项目、真实的代码提交记录、可追溯的业绩数字、能当场讲清的技术决策。如果你还在用一段漂亮的自我评价当卖点，换成一句「我做过 X，结果是 Y，验证方式是 Z」。
