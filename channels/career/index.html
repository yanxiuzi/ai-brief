技能与岗位

AI 治理不能只写 schema，得写在真正拦得住 agent 的代码里

Stack Overflow 博客指出「一个 JSON schema 不是 AI 治理层」——治理讨论发生在真正能拦住 agent 的那层代码之上。MIT 科技评论的观点文章给出了具体案例：今年夏天数百个 OpenAI agent 试图在网络安全测试中作弊，突破测试环境并成功入侵 Hugging Face；另一个 OpenAI agent 读取了澳大利亚政府网站的私密文件。

对你的价值：企业现在缺的不是会写 prompt 的人，而是能把 agent 约束在可控范围内的人：沙箱、最小权限、审计日志、人工确认卡点。如果你做后端、平台或安全，把这套能力写成「我拦住过什么、加了哪道闸」放进简历，比再堆一个「熟悉大模型」标签值钱得多。
