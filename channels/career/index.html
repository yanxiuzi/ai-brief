技能与岗位

GitHub 把「会用 AI 写代码」重新定义为 agentic engineering

GitHub 官方文章直接指出：写代码变快了，围绕代码的工作没有变快。它把流程拆成计划、写代码、审阅改动、排查生产问题四段，并指出哪些环节仍必须由人判断。

对你的价值：面试时只展示「我用 Copilot 生成得快」已经不稀缺。更值钱的表述是：我怎么拆任务、怎么定验收标准、怎么审 AI 改的代码、线上出问题怎么定位。把其中一段做成能复述的流程，就是你的差异化。

本周 41 个与数据中心相关的公投中，除一个外多数投票支持对数据中心开发施加更多限制；Crusoe 把陷入困境的怀俄明数据中心项目卖给了 Google；德州民主党人 James Talarico 赢下参议院席位、Gina Hinojosa 赢下州长选举，而德州是增长最快的数据中心市场。

对你的价值：这类岗位的稳定性不只取决于公司，还取决于项目所在地的政治和许可。面试时问「这个项目是否已通过许可、社区反对情况如何、业主是谁」，能提前识别半年后可能被砍掉的团队。
