技能与岗位

Agent 上生产已经被拆成六层，岗位要求落到「评估、置信度、成本、路由」

Stack Overflow 博客发布《Production-grade LLMs and agents: a field guide》，给出把 agent 从演示做成可依赖系统的成熟度模型，并配套 Part 1–6 逐层拆解：确定性层；evals 作为部署门禁以及如何发现漂移；置信度层（知道 agent 什么时候不知道）；安全与治理（guardrails、PII、审计、记忆）；可观测性、成本、路由与底层平台；以及「给编码 agent 的操作系统」——用一小组文件和规则，防止质量在数月、数千次编辑中衰减。Datadog 首席产品官 Yanbing Li 在同一博客谈对非确定性 agent 做可观测性、开发与生产流程边界模糊、AI 安全与 tokenomics。

对你的价值：这些就是当前 AI 应用岗 JD 里最值钱的关键词。简历写「用过某框架」没用，能写清「我加了哪层评估门禁、怎么发现漂移、怎么把 token 成本压下来」才有人看。面试前把六层当自查表，缺哪层补哪层。

Inc 报道，一名远程员工拒绝每天提交 160 张网络摄像头照片，随后被雇主解雇；该话题在 Hacker News 拿到 102 分、63 条评论。

对你的价值：远程和混合办公的隐形代价是监控。在终面或 offer 阶段用邮件问清：是否有定期截屏或摄像头拍照、打卡频率、采集数据的范围与留存期、违规后果。留下书面记录，出事时比「HR 当时口头说没问题」有用得多。
