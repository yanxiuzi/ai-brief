DeepSeek 发布 Super-agent 架构：Agent 脱离单次会话，AI 自己找 Bug 并提交 PR

10 月 31 日晚，DeepSeek Harness 团队在官方公众号发布技术文章《Super-agent 设计探索：迈向更自主的 Agent 系统》。团队认为，模型能力提升催生了个人助手（Personal Agent）的集中涌现，但主流 Agent 设计在多任务和团队协作规模上撑不住，多任务上限取决于人的注意力。突破方式是打破 Agent 与单次手动会话的绑定，让它成为跨会话保持上下文、同时推进多项复杂任务且互不干扰的连续实体，即 Super-agent。实现上采用双层架构、事件驱动、异步多信道交互、存算分离与外部 Watchdog，底层接管繁琐的会话管理。量子位称其已能自己找到 Bug 并提交 PR。

对你的价值：做 Agent 产品的可以直接参考它的分层思路：把「会话」从产品核心中移除，替换为常驻实体和事件驱动，是解决多任务互相打断的关键。另外需要提前评估成本：钛媒体的评测结论是「既强大又有边界感，就是费额度」，多任务并行会把 token 消耗成倍放大。

模型与产品

MiniMax H3 被 Pika 拿去开源：H3 Flex 六步去噪，画面和声音一起生成

Pika 发布基于 MiniMax H3 的衍生模型 Pika H3 Flex，开放适配器权重与推理代码。该模型通过六步去噪联合生成画面和声音，支持文本、首尾帧和多模态参考输入，用于镜头设计、参考生成和视频编辑。本次发布包含两套 LoRA 适配器，分别用于文本及首尾帧条件生成、多模态参考生成，同时提供 MiniMax H3 基础组件和本地推理工具。模型原生支持 480P、768P 输出，可生成约 5 至 15 秒的视频及同步立体声音频。Pika 提供 ComfyUI 工作流和 Hugging Face Diffusers 接入方式；本地生成之外，还可通过 API 做 1080P、2K、4K 视频增强和音频分轨。

对你的价值：做短视频和广告物料的团队可以按「低分辨率生成草稿→筛选→API 高分增强」的流程降低成本，音视频一次生成省掉后期对轨环节。代价是需要接受 5–15 秒的时长上限，长片仍得拼接，分镜设计要按「段」来重新规划。
