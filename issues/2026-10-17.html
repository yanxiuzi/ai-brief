Meta 发布 Muse Spark Open：816B 总参数、42B 激活、100 万上下文，两台 Mac Studio 就能跑

Meta 发布开放权重模型 Muse Spark Open，官方称其为「美国目前最强的开源权重模型」。该模型为多模态架构，8160 亿总参数、激活参数 420 亿（MoE），支持 100 万 Token 上下文，定位编码与 agentic 任务。它利用了苹果开源数组框架 MLX，针对 Apple Silicon 统一内存优化，可运行在搭载 M5 Ultra 芯片的 Mac Studio 上——M5 Ultra 最大支持 512GB 内存，两台顶配 Mac Studio 就相当于一台 1TB 统一内存的计算机，可容纳整个模型。模型已发布在 Hugging Face。扎克伯格在 X 上发帖感谢「John Ternus 和苹果」的合作；英伟达技术博客同时给出在 GB300 NVL72 上扩展其 agentic coding 工作流的方案。

对你的价值：本地跑大模型的性价比线又被推高了一截：816B 的 MoE、只激活 42B，意味着你可以用两台 Mac Studio 把整个模型装进机房，数据不出内网。对金融、医疗、有强数据合规要求的企业，这是私有化部署的新选项；对做 agentic coding 的团队，重点看激活参数带来的推理成本结构，而不是总参数。采购前先确认你的场景是「编码 + 工具调用」，而不是通识问答。
