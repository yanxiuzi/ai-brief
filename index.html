过去两周开发者把 Claude Code 的终端玩法彻底带偏：有人在输入框上方养了一只像素宠物，Claude 每调用一次工具它就吃一口饭，调用失败当场生病，碰上 rm -rf 还会抱头惊慌；有人把 Chrome 断网时的小恐龙搬了进来，Claude 在后台写业务逻辑，人在前台狂按空格跳仙人掌；有人做了 4-7-8 呼吸引导动画，答案一出来动画自动消失；最离谱的 Storytime 往 Claude Code 里塞了一个 26 万参数的小模型，根据 Claude 正在干的活实时在屏幕上方写故事。
