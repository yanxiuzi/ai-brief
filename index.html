黄仁勋与纳德拉同台：英伟达微软用 RTX Spark 把 AI Agent 塞进 Windows PC

在旧金山一场微软活动上，英伟达创始人兼 CEO 黄仁勋与微软 CEO 萨提亚·纳德拉共同介绍了双方正在协同设计的软硬件方案，目标是让 AI Agent 在 Windows PC 上运行。黄仁勋表示，英伟达当年就是因为 Windows 而创立的，现在 AI Agent 要进入 Windows。同期英伟达博客提到，DGX Spark 将于本月推出 64GB 统一内存版本，由 Acer 等主要厂商伙伴供货。

工具与玩法

Claude 动态多 Agent 工作流公测：主 agent 写计划，分阶段派活再合并结果

Claude 官方把动态多智能体工作流（Claude Managed Agents dynamic workflows）放进了公开测试版。ClaudeDevs 称这是一种为最庞大工作负载设计的多智能体编排：一个主 agent 写计划，计划跨多个 agent 分阶段运行，最后合并结果。官方在一条 116k 行的代码库里做了埋点对比实验。

对你的价值：大仓库、长链路改造（跨模块重构、批量迁移、遗留代码排查）是单 agent 最容易失控的场景。可以拿一个真实大仓库任务做对照：单 agent 跑一遍、动态多 agent 跑一遍，比较「任务完成比例」和「人工 review 时间」。别只看 agent 生成了多少代码，review 才是真瓶颈。
来源：OSCHINA（2026-10-10）https://www.oschina.net/news/502951

变现机会

硅谷「谁有算力谁是爹」：VC 开始囤 GPU，可提供算力的新云不到一年多了 55%

量子位以「硅谷 AI 现状：谁有算力谁是爹」为题报道，马斯克在连横 A 社（Anthropic），硅谷 VC 开始囤 GPU。CNBC 援引一位行业研究者称，能提供 GPU 容量的新云（neocloud）已超过 300 家，不到一年数量上涨约 55%。同期由于 AI 热耗尽内存产能，DDR5 内存价格一年内飙升可能高达 10 倍：32GB 的 Corsair Vengeance DDR5 售价 620 美元，同规格 DDR4 只要 260 美元。

对你的价值：算力正从「按需购买的服务」变成「可以囤的资产」。有渠道、有运维能力的团队，做二手卡转租、区域小集群、闲置算力调度，现在仍有价差空间；反过来，业务重度依赖 GPU 的公司别只签一家云，把备份供应商和价格锁定期写进合同。要当心的是，这轮涨价的源头是内存和先进制程产能被 AI 服务器吃掉，短期看不到回落。
