库克在采访中确认，苹果智能（Apple Intelligence）首批功能将于今年 10 月底在中国大陆推出测试版，接入阿里千问大模型。首批落地的是写作工具、图像消除、实时翻译这一类功能，全新 Siri AI 助手不在这次测试范围内。另有多家媒体报道称，国行正式版有望 12 月上线，百度、阿里均参与合作。

模型与产品

Meta 发布 Muse Spark Open：816B 总参数、42B 激活、100 万上下文，两台 Mac Studio 就能跑

Meta 发布开放权重模型 Muse Spark Open，官方称其为「美国目前最强的开源权重模型」。该模型为多模态架构，8160 亿总参数、激活参数 420 亿（MoE），支持 100 万 Token 上下文，定位编码与 agentic 任务。它利用了苹果开源数组框架 MLX，针对 Apple Silicon 统一内存优化，可运行在搭载 M5 Ultra 芯片的 Mac Studio 上——M5 Ultra 最大支持 512GB 内存，两台顶配 Mac Studio 就相当于一台 1TB 统一内存的计算机，可容纳整个模型。模型已发布在 Hugging Face。扎克伯格在 X 上发帖感谢「John Ternus 和苹果」的合作；英伟达技术博客同时给出在 GB300 NVL72 上扩展其 agentic coding 工作流的方案。

对你的价值：本地跑大模型的性价比线又被推高了一截：816B 的 MoE、只激活 42B，意味着你可以用两台 Mac Studio 把整个模型装进机房，数据不出内网。对金融、医疗、有强数据合规要求的企业，这是私有化部署的新选项；对做 agentic coding 的团队，重点看激活参数带来的推理成本结构，而不是总参数。采购前先确认你的场景是「编码 + 工具调用」，而不是通识问答。
来源：Solidot、OSCHINA、NVIDIA 开发者博客

工具与玩法

千问办公接入中控技术：Agent 先切营销全链路，再横向铺采购、供应链、财务、人力、研发

中控技术正式接入千问办公，将 Agent 落地营销全链路，覆盖从搜集市场线索到回款结算的完整流程；后续千问办公还将优化中控技术的采购、供应链、财务、人力、研发等场景工作流，双方要共建流程工业领域的 AI Native 标杆企业。中控技术成立于 1999 年，业务覆盖全球 50 多个国家和地区，服务海内外 4 万多家客户。签约现场由中控技术副总裁石小磊、阿里云智能集团副总裁张敬、千问办公副总裁朱鸿共同见证。报道提到一线销售的典型负荷：白天跑客户，晚上写材料。

对你的价值：这是目前国内最清晰的一份「办公 Agent 落地顺序表」：先做营销链路（线索到回款，结果可量化），再横向复制到采购、供应链、财务、HR。如果你在企业里推 AI 或做交付乙方，照这个顺序谈、把营销链路的数字跑出来，后面的预算会好拿得多。对个人来说，「白天跑客户、晚上写材料」这句话已经点明了哪个环节最先被替掉。
